# Final Project

Start here:

1. [`00_project_kickoff.md`](00_project_kickoff.en.md) — a bridging exercise: writing your first test
   yourself, before you start the project itself.
2. [`01_final_project_brief.md`](01_final_project_brief.en.md) — the full project description:
   required behavior, invariants, acceptance criteria, your own tests, design choices, optional
   extensions, Git workflow, and the defense.

The starting code at this point (`final-project-start`) is functionally equivalent to
`module-09-solution` — this directory contains only the project's starting material, not a solution
or a `TODO`-filled skeleton.
